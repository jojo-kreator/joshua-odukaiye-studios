Client gallery maker

This page runs on your own computer. Nothing you type here is sent anywhere.

  1. In Google Drive, share the client's folder as Anyone with the link can view, then copy its link.
  2. Paste the link below and click Create entry.
  3. Send the client the access code. Copy the line into galleries.js (between the square brackets) and upload that file to GitHub.

Keep a private note of which code belongs to which client. The line itself does not say, and it cannot be turned back into the link without the code.
